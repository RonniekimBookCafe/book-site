실습 자료 다운로드

책과 로봇 프로젝트에서 쓰는 로봇 파일, 한국어 소스, 영어 소스를 한곳에서 받습니다. 책 표지 왼쪽 위의 코드로 찾으면 가장 빠릅니다.

    1. 로봇 파일 받기ZIP을 풀고 RoboCo에서 로봇을 불러옵니다. Steam Workshop 모델은 구독하면 RoboCo에 나타납니다.
    2. 소스 코드 받기책과 같은 언어의 소스 ZIP을 받아 RoboCo Scripts 폴더 바로 아래에 풉니다. 한국어·영어 소스는 주석과 README 언어만 다릅니다.
    3. 책의 CHAPTER대로 실행Microcontroller에 시작 파일을 연결하고 책의 순서대로 실행합니다. 자세한 위치와 순서는 각 책의 설치 안내에 있습니다.

    파일 확인값 (SHA-256)

    받은 파일이 손상되지 않았는지 확인할 때 씁니다. 파일이 바뀌면 버전과 함께 이 값도 바뀝니다.

    확인값 보기
    파일크기SHA-256

    이용 안내

    • 파일은 Steam용 RoboCo에서 씁니다. 별도의 시스템 Python 설치는 필요하지 않습니다.
    • 소스 ZIP에 든 Educational Library(C01_Lib, Q01_Lib …)는 책의 실습을 위해 저자가 만든 코드이며 RoboCo 공식 API가 아닙니다.
    • 코드만으로도 첫 실행은 할 수 있지만, 무엇을 관찰하고 어떤 값을 바꿔 비교하는지는 책에서 다룹니다.
    • RoboCo는 Filament Games가 만든 게임입니다. 이 파일들은 RoboCo 공식 예제나 공식 교재가 아닙니다. 사용과 재배포 조건은 각 책의 저작권 안내를 따릅니다.
