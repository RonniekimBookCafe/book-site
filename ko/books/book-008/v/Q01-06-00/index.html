영상 소개

Steam RoboCo에서 4족 로봇의 세 관절 HX·HY·KN을 개별적으로 제어하는 LEG1 전체 동작 영상입니다.

한 다리의 3자유도 관절 구조를 확인하고, 앞뒤·좌우·무릎 움직임을 각각 제어합니다.

FL·FR·HL·HR 네 다리를 선택하여 관절의 회전 방향을 비교하고, 자동 테스트를 통해 다리별 움직임과 좌우 대칭성을 확인합니다.

주요 실습 내용

키동작
W / SHY 관절 앞뒤 이동
A / DHX 관절 좌우 이동
E / QKN 관절 굽힘·폄
U / O / J / LFL·FR·HL·HR 다리 선택
K선택한 다리의 관절을 90도로 이동
1~4다리별 관절 자동 테스트
5네 다리의 HX 벌리기 테스트
6관절 조합 자세 변화 테스트
0관절 영점 자세
F1키 안내
F2기본 자세 복귀
F3자동 테스트 중단

LEG1의 숫자 0은 모든 관절을 90도로 이동시키는 관절 영점 자세입니다. F2의 기본 서기 자세와는 다른 상태입니다.

영상에서 볼 것

  • HX·HY·KN이 각각 어느 방향으로 도는지
  • 같은 키를 눌러도 왼쪽 다리와 오른쪽 다리가 반대로 보이는 장면
  • 화면의 Port 번호와 실제로 움직인 관절의 짝
