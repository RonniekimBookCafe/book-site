영상 소개

Steam RoboCo에서 4족 로봇의 발끝 목표 좌표를 변경하고, 역기구학(Inverse Kinematics, IK)으로 관절 각도를 계산하는 LEG2 전체 동작 영상입니다.

발끝의 목표 위치를 x·y·z 좌표로 지정하면 저자 제공 Python 라이브러리에서 IK를 계산하고, 계산된 관절 각도를 RoboCo의 ServoMotor로 전달합니다.

선택한 다리의 발끝을 앞뒤·좌우·위아래로 움직이고, 원형 궤적을 실행하면서 발끝 위치와 관절 각도의 관계를 확인합니다.

주요 실습 내용

키동작
W / S발끝 x 좌표 증가·감소
A / D발끝 y 좌표 증가·감소
E / Q발끝 z 좌표 증가·감소
U / O / J / LFL·FR·HL·HR 다리 선택
I발끝 원형 궤적 자동 테스트
K선택한 다리 기본 자세
F1키 안내
F2네 다리 기본 자세
F3원 그리기 중단

화면의 FK 오차는 계산된 관절 각도를 이용해 다시 구한 좌표와 목표 좌표의 차이입니다. 실제 발끝 위치를 별도로 실측한 값과는 구분합니다.

화면에서 확인하는 계산 흐름

  1. 발끝 목표 좌표
  2. IK 계산
  3. HX·HY·KN 관절 각도
  4. 서보 목표
  5. FK 계산 결과 비교

영상에서 볼 것

  • 목표 좌표가 바뀔 때 세 관절이 동시에 함께 움직이는 모습
  • 화면의 IK 각도와 서보에 보낸 각도가 서로 다른 숫자인 점
  • 원 그리기에서 발끝이 그리는 궤적
