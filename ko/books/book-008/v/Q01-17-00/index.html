영상 소개

Steam RoboCo에서 4족 로봇의 IMU 센서와 PID 제어를 이용해 기울어진 시험대 위에서 균형 보정을 수행하는 BALANCE 전체 동작 영상입니다.

3축 기울기 시험대의 Roll·Pitch·Yaw를 변경하고, 로봇의 IMU가 측정한 자세 정보로 보정 각도를 계산합니다.

균형 보정을 끈 상태와 켠 상태를 비교하고, PID의 KP·KI·KD 값을 변경하여 제어 동작의 차이를 관찰합니다.

주요 실습 내용

키동작
W / S시험대 Pitch 증가·감소
A / D시험대 Roll 감소·증가
Q / E시험대 Yaw 증가·감소
1시험대·로봇 IMU 방향 확인
2균형 테스트
3균형 OFF/ON 비교
4균형 제어 활성화·비활성화
5시험대 수평 복귀
6 / 7시험대 동작 속도 감소·증가
8흔들기 테스트
U / JKP 증가·감소
I / KKI 증가·감소
O / LKD 증가·감소
F1키 안내
F2기본 자세 및 영점 복귀
F3테스트 중단

BALANCE에는 두 개의 Microcontroller가 사용됩니다. 로봇 관절·센서 제어와 시험대 서보 제어가 서로 다른 Python 스크립트로 실행됩니다.

제어 구조

  1. 시험대 기울기
  2. IMU 측정
  3. 필터 처리
  4. PID 보정 계산
  5. 관절 목표 변경
  6. 자세 반응

영상에서 볼 것

  • 균형 OFF와 ON에서 몸통이 기우는 정도의 차이
  • 시험대가 멈춘 뒤 몸통이 수평으로 돌아오는 속도
  • KP·KI·KD 값을 바꿀 때 콘솔에 남는 기록
