WALK 보행 전체 동작 YouTube 공개

WALK 모델에서 전진·후진·제자리 회전·옆 걸음과 자동 모드를 차례로 실행한 장면입니다. 키를 누르는 동안 걷고, 손을 떼면 네 발을 바닥에 놓고 기본 자세로 돌아옵니다.

YouTube에서 보기 ↗ (새 탭에서 열림)

영상에서 볼 것

  • 대각선으로 마주 보는 두 다리가 함께 들리고 함께 내려오는 순간
  • A·D 제자리 회전과 Q·E 옆 걸음에서 몸통이 보는 방향이 어떻게 다른지
  • 키를 놓은 뒤 네 발이 모두 바닥에 닿기까지 걸리는 짧은 시간

ACTION 퍼포먼스 전체 동작 YouTube 공개

숫자 키 1~9에 준비된 몸짓을 차례로 실행한 장면입니다. 같은 열두 관절이 걷기 말고도 인사, 앉아서 손 흔들기, 팔굽혀펴기, 물구나무서기, 탭 댄스 같은 자세를 만듭니다.

  • 어떤 동작에서 바닥에 남아 몸을 받치는 발이 몇 개인지
  • 한 동작이 끝나고 기본 자세(0)로 돌아오는 순서

LEG1 3자유도 관절 제어 YouTube 공개

관찰용 거치대에 올린 로봇에서 다리 하나의 세 관절 HX·HY·KN을 키로 하나씩 움직인 장면입니다. 로봇 화면에 입력·모터 각도·Port 번호가 함께 나타납니다.

YouTube에서 보기 ↗ (새 탭에서 열림)

영상에서 볼 것

  • HX·HY·KN이 각각 어느 방향으로 도는지
  • 같은 키를 눌러도 왼쪽 다리와 오른쪽 다리가 반대로 보이는 장면
  • 화면의 Port 번호와 실제로 움직인 관절의 짝

LEG2 역기구학 IK 제어 YouTube 공개

발끝 목표 위치 x·y·z를 키로 옮기면 IK가 세 관절 각도를 계산해 다리를 움직이는 장면입니다. 원 그리기 테스트에서는 발끝이 정해 둔 원을 따라갑니다.

  • 화면의 IK 각도와 서보에 보낸 각도가 서로 다른 숫자인 점
  • 원 그리기에서 발끝이 그리는 궤적

LEG3 네 다리 협응 제어 YouTube 공개

네 다리를 함께 다루는 테스트 1~9를 실행한 장면입니다. 도달 범위 확인, 관절 한계, 한 다리씩 들기, 대각선 다리, 세 다리 자세, 걸음 순서까지 이어집니다.

YouTube에서 보기 ↗ (새 탭에서 열림)

영상에서 볼 것

  • 한 다리를 들 때 나머지 세 다리가 몸통을 받치는 모습
  • 대각선 다리 두 개가 짝을 이루어 움직이는 순서
  • 닿을 수 없는 목표에서 명령을 보내지 않고 멈추는 장면

  • 화면판 그래프의 점이 실제 기울기를 따라가는 모습
