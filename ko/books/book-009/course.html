피지컬 AI로 배우는 RoboCo · 6권 시리즈

목적에 맞게 책을 고르고,
대상에 맞게 수업을 짭니다

이 페이지는 시리즈 여섯 권의 조합과 초등학교·중학교·고등학교·대학교·일반인을 위한 수업 일정 예시를 정리합니다. QUAD-02이 포함된 조합과 일정은 노란색으로 표시했습니다.

각 권은 해당 권의 로봇 파일·시작 파일·Library만으로 실행할 수 있는 독립 교재입니다. 아래 조합은 선수 조건이 아니라 학습 목적에 따른 권장 연결입니다.

6권 시리즈 구성

CORE 트랙 · 기반 MOVE → SENSE / REACT → MANIPULATE

CORE-01MOVE / CONTROL피지컬 AI로 배우는 RoboCo 로봇 구조와 Python 제어출간CORE-02SENSE / REACT피지컬 AI로 배우는 RoboCo 센서 피드백과 로봇 제어출간 예정CORE-03MANIPULATE피지컬 AI로 배우는 RoboCo 로봇팔과 작업 제어출간 예정

QUAD 트랙 · 4족 프로젝트 WALK → DECIDE → WORK

QUAD-01WALK피지컬 AI로 배우는 4족 로봇 구조와 보행 제어출간 예정QUAD-02DECIDE피지컬 AI로 배우는 4족 로봇 자율보행과 AI출간 예정QUAD-03WORK피지컬 AI로 배우는 4족 로봇 이동 조작과 작업 자동화출간 예정

CORE-01 ↔ QUAD-01, CORE-02 ↔ QUAD-02, CORE-03 ↔ QUAD-03은 대응하는 개념을 다룹니다. 두 트랙을 세로로 연결해 읽을 수도 있습니다.

평가 기준 예시

코드의 길이가 아니라 움직임과 설명, 비교와 개선을 평가합니다.

  1. 로봇이 목표대로 움직였는가
  2. 왜 그렇게 움직였는지 제어 구조로 설명하는가
  3. 바꾼 값 하나와 변경 전후 결과를 기록했는가
  4. Console LOG에서 실패한 단계를 찾았는가
  5. 한 조건만 고쳐 다시 성공시켰는가
