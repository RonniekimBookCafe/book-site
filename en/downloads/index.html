RESOURCES

Robot files and source code

Robot files, Korean source, and English source for the books and robot projects, all in one place. The code at the top left of each cover is the quickest way to find yours.

    1. Get the robot filesUnzip and load the robot in RoboCo. Steam Workshop models appear in RoboCo once you subscribe.
    2. Get the source codeDownload the source ZIP in your book's language and unzip it directly under the RoboCo Scripts folder. The Korean and English sources differ only in comments and README.
    3. Run it chapter by chapterAttach the start file to the Microcontroller and follow the book. Each book's setup guide shows the exact folder and order.

    Terms of use

    • The files are for RoboCo on Steam. No separate system Python is needed.
