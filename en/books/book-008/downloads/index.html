Install and first run

  1. In RoboCo, click OPEN SCRIPT FOLDER in the Microcontroller settings to open your Scripts folder.
  2. Unzip and place the whole Book_Q01_Robot folder directly inside Scripts. Don't rename it or move Q01_Lib out.
  3. Load the Book-QUAD-01-WALK model you subscribed to on Steam Workshop.
  4. On the robot's Microcontroller, click LOAD, choose q01_walk_start.py, and enter Live Mode.
  5. When the console shows the QUAD-01 WALK (Book-QUAD-01-WALK) box and [STATE] ready, click the game window once and hold W. If the robot walks, you're set up.
If you get stuck: a ModuleNotFoundError usually means Book_Q01_Robot ended up one level deeper than Scripts. If the console shows raw <color=#...> text, set LOG_COLOR to False in the start file. The other keys and the exercise order continue from PART 1 of the book.
