About this video

A full run of ACTION, which combines the quadruped's twelve joints into different poses and performances in RoboCo on Steam.

Number keys 0–9 run distinct moves, from the standing pose to a greeting, sitting and waving a front paw, a stretch, push-ups, and a handstand.

Each move is built from predefined joint targets and an execution order. Changing joint angles and their order lets one robot produce many different motions.

Keys in this exercise

KeyAction

Press a number key once to run its move. By default, a key pressed during a move can be queued, so to check moves one at a time, wait until the previous move finishes before pressing the next key.

What to watch

  • How body height changes from one performance to the next
  • How many feet stay down to hold the body in each one
  • How each performance returns to the standing pose (0)
