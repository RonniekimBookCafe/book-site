About this video

A full run of the WALK model: a twelve-joint (12 DOF) quadruped built in RoboCo on Steam.

A Python script controls all four legs to walk forward and back, turn in place, side-step, and run automatic gait patterns.

The video works through the keys assigned to the WALK model in order, so you can see how the robot's motion changes with each input.

Keys in this exercise

KeyAction
W / SWalk forward / backward
A / DTurn left / right in place
Q / ESide-step left / right
XStop pose
ZRelaxed pose
1Auto mode: basic moves
2Auto mode: walking at different heights
3Auto mode: complex pattern
0Relax, then end the script

Direction keys keep the robot walking while held and return it to the default pose when released. Number keys 1, 2, and 3 run prepared automatic gait patterns.

What to watch

  • The moment two diagonal legs lift and land together
  • How the body's heading differs between A/D turns in place and Q/E side steps
  • The short settle after you let go, until all four feet are down
