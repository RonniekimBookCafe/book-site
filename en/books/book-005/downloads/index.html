Start file and Educational Library

Robot 2 runs a single start file, c01_start.py. The C01_Lib folder is the author's Educational Library that the start file calls; it is not part of the official RoboCo API. Appendix E of the book maps where the official API ends and the library begins.

Three install rules

  1. Put Book_C01_Robot directly under Scripts. If it ends up one folder deeper, the start file can't find the library.
  2. Don't rename the folders or files.
  3. When you install a new version, delete the old folder first. Copying over it can leave old files behind.
